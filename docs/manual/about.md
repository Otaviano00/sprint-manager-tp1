## Sobre

O SprintManager é um software de gerenciamento de projetos seguindo o Framework Scrum.
Ele foi feito como projeto final da matéria `Técnicas de Programação 1 - UnB 2026.1` e atende os critérios de correção estabelecidos.
Foram implementadas funcionalidades essenciais para que esse software cumpra seu objeito. Elas são:

- Autentição
- Gerenciamento de Histórias de Usuário
- Gerenciamento de Pessoas
- Gerenciamento de Projetos
- Gerenciamento de Planos de Sprint

Esses módulos interagem entre si e seguem as regras de negócios estabelecidas no projeto intrinsícas ao Framework Scrum.
